## 🧩 About

**Mafia The Old Country Helper** is a curated list of Mafia The Old Country open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, waypoint switcher
- **Quality-of-Life Helpers** — inventory catalog, loadout manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Waypoint Switcher — review route from any checkpoint
- Show Markers — visualize objective markers
- Route Notes — record and review mission runs
- Playback Speed — adjust study playback (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Vehicle Catalog — browse cars, colors, upgrades
- Custom Loadout Notes — organize weapon and gear presets
- Visibility Notes — improved marker visibility

### 🏋️ Sandbox Layout
- Sandbox Notes — segment study on any district
- Camera Control — manually adjust camera in study mode
- Input Buffer Notes — chain complex maneuvers in the editor
